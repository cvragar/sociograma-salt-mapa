# Sociograma comunitari de Salt · mapa

Versió amb mapa base OpenStreetMap, xarxa de relacions, directori i planificador comunitari per als CAP Salt 1 i Salt 2.

**Obrir el web:** https://cvragar.github.io/sociograma-salt-mapa/

Revisió selectiva: 8 d’octubre de 2026. 267 fitxes, 495 relacions i 121 fitxes geolocalitzades. Les fonts, hipòtesis i validacions pendents es poden consultar a la mateixa aplicació.

## Fitxers

- `index.html`: aplicació completa, amb dades, estils i biblioteques integrats. El fons de carrers necessita connexió a OpenStreetMap.
- `Sociograma_Salt_mapa_corregido_fuentes.zip`: codi font modular complet, dades, CSV, scripts, llicències i documentació de la revisió.

L’aplicació funciona sense instal·lació. El pla de treball es desa al navegador i es pot exportar. No se sincronitza entre dispositius.

Aquest repositori publica una versió separada. La versió anterior continua a https://cvragar.github.io/sociograma-salt/.

## Abast

Salt urbà, CAP Salt 1 i CAP Salt 2. No es representen límits oficials d’adscripció entre els dos CAP perquè no se n’ha obtingut un polígon o un carrerari oficial. Les relacions amb fonts internes i les hipòtesis es distingeixen de les sustentades en fonts públiques. La revisió de les fonts és selectiva i no equival a una validació integral de totes les relacions.

Cartografia de fons: © OpenStreetMap contributors. Cytoscape i les seves llicències estan inclosos en el HTML i el paquet de fonts.
